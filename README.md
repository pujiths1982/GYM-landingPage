# IRONCORE – Gym Equipment Landing Page

IRONCORE is a simple and modern gym equipment website made using **HTML and CSS**. It shows different gym products with prices, reviews, and product details.

### Features
- Simple and clean design
- Gym equipment products
- Product prices and ratings
- Responsive design for mobile and desktop
- Hover effects and simple animations
- Featured product section
- Customer reviews

### Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
